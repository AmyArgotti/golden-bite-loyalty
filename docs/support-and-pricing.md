# Support And Pricing Guidance

## Suggested Commercial Structure

For a professional restaurant deployment, separate the work into:

- one-time build and launch fee
- monthly support and hosting management
- pass-through third-party costs

## Suggested Build Fee

For the delivered MVP scope, a fair custom build range is:

- `$7,000` to `$12,000`

Price higher if you are also handling:

- live deployment
- wallet certificates
- restaurant staff onboarding
- launch-day support
- post-launch fixes

## Suggested Monthly Support

A reasonable support retainer is:

- `$250` to `$750` per month

This can include:

- uptime checks
- basic bug fixes
- backup verification
- dependency updates
- admin/staff support

## Third-Party Costs

These should usually be billed separately or passed through:

- VPS hosting
- domain and SSL
- Twilio or other SMS provider
- Sentry or monitoring services
- Apple developer/account costs if applicable

## Suggested Support Scope

### Included

- monitoring review
- small bug fixes
- backup checks
- deploy assistance for small updates
- admin/staff account help

### Not Included By Default

- major new features
- POS integration
- campaign automation
- referral system expansion
- Google Wallet support
- redesign work

## Launch Support Option

Offer an optional launch package that includes:

- production deployment
- real OTP verification
- real wallet verification
- staff onboarding session
- same-day launch support

## Recommendation

Do not offer unlimited support informally. Put in writing:

- what response time the client gets
- what counts as a bug vs new work
- whether hosting and SMS are included or billed separately
