# Pricing Guidance

## Your Build Cost As A Programmer

If you build this properly as a real production service, your main cost is your time.

### Lean MVP estimate

Scope:

- OTP auth
- customer dashboard
- staff panel
- loyalty engine
- audit logs
- Apple Wallet
- Android PWA card

Estimated effort:

- `180-260` hours for a solid solo build

At common freelance rates:

- `$25/hour`: `$4,500-$6,500`
- `$40/hour`: `$7,200-$10,400`
- `$60/hour`: `$10,800-$15,600`

### More complete v1 estimate

Adds:

- referrals
- birthday rewards
- campaigns
- fraud monitoring
- reporting polish
- deeper admin features

Estimated effort:

- `280-420` hours

At common freelance rates:

- `$25/hour`: `$7,000-$10,500`
- `$40/hour`: `$11,200-$16,800`
- `$60/hour`: `$16,800-$25,200`

## Monthly Running Cost

For one restaurant branch:

- VPS: `$20-$80/month`
- Managed backups or object storage: `$5-$20/month`
- SMS: usually `$20-$150/month` depending on traffic and country
- Error monitoring: `$0-$30/month`
- Domain/SSL: `$1-$15/month` average effective monthly cost

Typical total:

- Lean setup: `$50-$150/month`
- Safer production setup: `$120-$300/month`

## What You Can Charge The Restaurant

### Option A: One-time setup + monthly support

- Setup/build fee: `$6,000-$15,000` for MVP
- Monthly maintenance/support: `$150-$600/month`
- Hosting and SMS billed separately or passed through with margin

This is the easiest model to sell.

### Option B: Setup fee + SaaS-style monthly fee

- Setup: `$2,000-$5,000`
- Monthly service: `$300-$1,200/month`

Use this if you will host, maintain, update, and support the system continuously.

### Option C: Premium custom platform

- Build fee: `$12,000-$30,000+`
- Monthly support: `$300-$1,500/month`

Use this only if they want POS integrations, campaigns, reports, and multi-branch scaling from the start.

## Best Recommendation

For Golden Bite, I would propose:

- MVP build: `$7,000-$12,000`
- Monthly support and hosting management: `$250-$500/month`
- SMS billed separately

That is strong enough to be professional, but still realistic for a single restaurant client.
